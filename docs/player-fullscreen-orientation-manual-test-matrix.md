## 判定口径

- **固定横屏**：前置摄像头或灵动岛位于左侧；全屏期间转动手机，界面不改变方向。
- **固定竖屏**：界面保持正常竖直方向；全屏期间转动手机，界面不改变方向。
- **恢复进入前状态**：退出动画完成后，界面方向与点击全屏按钮前完全一致。
- **播放状态保持**：进入前正在播放则退出后继续播放；进入前暂停则退出后仍暂停。
- **通过**：方向、动画、页面栈、播放状态全部符合预期，且没有明显黑屏或闪烁。
- 结果填写 `通过`、`失败` 或 `阻塞`。失败时记录日志起止时间，避免只截取单条日志。

## 建议执行顺序

1. 先执行 A01、A04、A07、A09、A12，快速判断进入锁定和退出恢复是否成立。
2. 五条都通过后完成 A 组与 B 组。
3. 再执行 C、D 组，确认分 P、直播和导航生命周期没有回归。
4. 最后执行 E 组中的镜像、后台、PiP、AirPlay 和 iPad 场景。
5. 任一核心用例失败时先停止同类重复测试，导出完整 `ibili-current.log` 并按失败模板记录。
